# Panduan Pengguna

## Super Admin
1. **Tenants** → buat organisasi (slug otomatis).
2. **Content Library** → buat modul; **Quizzes** → tambah pertanyaan.
3. **Plans & Billing** → kelola paket.
4. **Reports** → pantau awareness lintas organisasi.

## Tenant Admin
1. **Users** → tambah manual atau import CSV (`name,email,role`).
2. **Training** → tugaskan modul; user mendapat notifikasi.
3. **Tabletop Sessions** → pilih skenario dan Playbook → siapkan tim serta peserta.
   Untuk Playbook terstruktur, tetapkan Primary dan Support pada fase yang relevan,
   lalu tandai sesi **Ready**. Pembuat sesi menjalankan inject dari Facilitator Console,
   menyelesaikan Debrief (rating, Evidence, Finding, Action Item, dan AAR), lalu
   memfinalisasi sesi untuk membuka Result. Sesi lama V1 tetap dapat dibaca.
4. **Reports** → lihat skor per anggota; **Download CSV** untuk manajemen.
5. **Billing** → pilih plan sesuai jumlah user.

## User
1. **Training** → baca materi → quiz (skor lulus 70).
2. **Case Studies** → pilih keputusan terbaik per scene.
3. **CTF** → submit flag; poin masuk skor.
4. **Tabletop — My Exercises** → buka briefing tim, lalu isi keputusan, alasan,
   tindakan segera, dan koordinasi/handoff untuk inject aktif. Respons dapat
   diperbarui bersama anggota tim sampai fasilitator mengunci inject; Result
   tersedia setelah sesi selesai.
5. **My Score** → pahami 5 komponen skor Anda.
6. **Notifikasi** → pantau penugasan baru.
